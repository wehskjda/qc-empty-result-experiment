# C1 与页面顺序实验的编码前手推预期

状态：在第二版策略程序编写和运行前保存；下列数值均为手工推导预期，不是实际执行结果。原第一版故障正文、源页参考内容与关键数字均保持不变。

## 新增规则

C1 完全沿用 C 的新增验收页信号、S/E 更新、预算、方式切换及同页同方式次数限制，只在文档停滞暂停条件中增加一个前提：四个稳定源页均至少实际调用过一次。网络失败也算该源页已尝试，不要求验收通过，也不要求 T/O 每种方式都试过。

S 从第一次调用开始累计；全页首试覆盖前仅阻止停滞守卫生效，不阻止计数增长；新增验收页清零 S，网络保护只冻结 S。完成首轮不额外清零，达到覆盖且 S≥k 的同一次调用结束后即可停滞暂停。总预算与其他停止条件始终有效，不为了覆盖而额外增加预算。

## 网格及比较范围

初始顺序使用四个固定源页的全部24个排列，每个页面的正文、故障和第 n 次恢复条件绑定原页身份，不随队列位置改变。七个场景均做全部顺序，以便 S、R 和 L 在相同口径下比较。每个顺序与预算下运行 B 一组、C 的 k=2/3/4、C1 的 k=2/3/4，共7组；七场景×24顺序×2预算×7组=2352个主条件。另加原顺序1234的 A 两预算×七场景=14个回归条件，总计2366个唯一主条件。

原顺序子集共112条件，其中 A/B/C 的70条件须逐项回归第一版已保存结果，新增 C1 的42条件由 `manual_canonical_C1.csv` 独立预先给定。原顺序的 B/C/C1 同时属于全顺序实验，不能再次作为独立条件重复计数。

`expected_all_conditions.csv` 将本文件下列按特殊页位置分组的代数公式静态展开为2366条预期。生成过程只枚举场景、24排列、预算和策略参数后直接填入公式值，没有调度队列、逐次状态转移、调用策略引擎或计算实际运行结果。canonical A 的14行直接迁移第一版手推表。展开后已核对原70条与新42条canonical预期逐字段一致，2366个run_id唯一；核查摘要为 `expected_expansion_checks.json`。它和手推说明同属编码前输入，不得根据正式运行回改。

## 全24顺序的分组公式

令 j 为一个固定特殊源页在初始队列中的位置，每个 j 对应6个不同排列。以下行为由同一页固定故障序列决定，不是重新指定第 j 页的内容。

### B 基线

所有顺序下 B 的完成页数/调用相同：F/D 为3/11；N为4/6；P为4/4；R/S为4/7；L预算12为0/12、预算20为4/16。动作顺序可以不同，但源页的故障与恢复尝试号不变。

### F 与 D

F 的特殊页为固定 p1，D 为固定 p2。C1=C，所有停滞都发生在首试覆盖完成后。若特殊页位置 j≤3，最后一个正常页在总调用4通过，暂停总调用为4+k；若 j=4，最后一个正常页在总调用3通过，暂停总调用为3+k。均完成3页，影子累计11次仍3页，不算文档错停。

这意味着单个永久困难页的队列位置也能改变暂停调用数，但 C1 对这个变化没有作用。严格重复的定义沿用第一版，不把首次改用 O 算为重复。

### N 与 P

C1=C=B。N在任意顺序下均4/6，两个受保护网络失败实际占用该页 T 的尝试次数；P均4/4。无影子。

### R 同一页多次修复

特殊页是固定 p4，其他三页 T 首次通过。

| p4 初始位置 | k | C 与 C1 主运行 | 影子 |
|---|---|---|---|
| j=1、2、3 | 2 | 3页/6次，停滞 | 再1次，累计7次完成，损失1页 |
| j=1、2、3 | 3或4 | 4页/7次，完成 | 无 |
| j=4 | 2 | 3页/5次，停滞 | 再2次，累计7次完成，损失1页 |
| j=4 | 3 | 3页/6次，停滞 | 再1次，累计7次完成，损失1页 |
| j=4 | 4 | 4页/7次，完成 | 无 |

推导理由：p4排在前三位时，第四次总调用仍有正常页通过，重置 S；此后 p4 第二次、第三次失败分别产生 S=1、2，第四次通过先验收再清零。p4排在最后时，第一次失败就发生在最后一个新增之后，因此 k=3 也可能截断第四次成功。所有原 C 的 R 暂停已覆盖所有页，所以 C1 无法挽回它；仍保留顺序影响。

### S 三个困难页与一个容易页

容易页始终是固定 p4，困难页始终是 p1/p2/p3；只改变初始顺序。B均在总调用7完成。表内“停”均会由影子累计7次完成；当前0页损失4页，当前1页损失3页。

| p4 初始位置 | C k=2 | C1 k=2 | C k=3 | C1 k=3 | C/C1 k=4 |
|---|---|---|---|---|---|
| j=1 | 1页/3次，停 | 1页/4次，停 | 1页/4次，停 | 1页/4次，停 | 4页/7次，完成 |
| j=2 | 1页/4次，停 | 1页/4次，停 | 4页/7次，完成 | 4页/7次，完成 | 4页/7次，完成 |
| j=3 | 0页/2次，停 | 4页/7次，完成 | 4页/7次，完成 | 4页/7次，完成 | 4页/7次，完成 |
| j=4 | 0页/2次，停 | 4页/7次，完成 | 0页/3次，停 | 4页/7次，完成 | 4页/7次，完成 |

若原 C 在容易页前已停滞，C1允许实际尝试到容易页，它的新增成果会把 S 清零，随后 OCR 成功接续产生新增。若容易页最先或较早通过，首轮结束时已有连续困难页使 S 达阈值；覆盖门刚打开便允许暂停。首轮没有人为清零，所以不能预期 C1 对全部顺序都完成。

每个预算下，S中 C 的 k2/3/4 预期完成顺序数为0/12/24，C1为12/18/24。C1缓解未尝试源页被一起放弃，但仍有12/6/0种顺序不能完整完成。相同内容和故障下这些是24排列的穷举描述，不是随机总体成功率。

### L 所有页第四次才通过

所有页对称。C在第k次总调用暂停，主结果0页；C1在第4次首试覆盖完成时立即暂停，S仍为4，因此三个k均主结果0/4。无首轮重置。C1相对C多调用2/1/0次，不挽回页面。预算12时影子最终0页/累计12次，预算20时影子最终4页/累计16次。所有24顺序的数量结果相同，具体通过顺序随初始队列变化。

## 可核对的全排列合计预期

这些合计由上方分组公式直接展开，用于补充核验，不能替代逐条原始输出。

- 每种 C/C1 各1008个参数条件。C预期564个停滞暂停、204个文档错停；C1预期528个停滞暂停、168个文档错停。
- 两者差额仅来自S：C1使36个原本错停的参数条件完成文档，每条件挽回4页，共144个“页面×参数条件”。不可当成144个不同真实页面。
- 全部1008对 C1−C 比较，C1预期主调用增加324次：S增加180次，L增加144次；F/N/D/P/R不增加。新增严格重复次数预期为0，因为S新增的是首试或首次OCR，L新增的是不同源页的首试候选。
- C停滞时预期144个参数条件存在从未实际尝试的源页：S占48、L占96；C1的此类停滞为0。这个保证只涉及“停滞暂停”，预算耗尽始终允许提前结束，不能被描述为任何预算下都保证全页覆盖。
