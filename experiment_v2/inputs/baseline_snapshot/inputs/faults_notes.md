# 确定性故障返回材料说明

状态：在实验程序实现前固定的输入材料；本文件不是实测结果。

`faults.json` 保存实际返回正文与结构化状态，不包含验收通过布尔值或预设CER。解析器回放只读取静态返回，验收器必须对text自行计算距离并从正文提取关键数字。

索引为场景、源页、方式与该页该方式第n次调用。overrides 中 attempts 精确键优先；其次为满足 repeat_from 的 repeat_response；无匹配时使用 default_response_by_page。所有方式都仅为固定的T/O，索引不含策略名称、预算、k或全局调用序号。

数据准备方法：从已审阅的四页Markdown中读取四个text代码块；合格正文原样保存。R/L将正文尾部round(正文字符数×目标比例)个字符替换为原文从未出现的“※”，不改变长度。开头三项关键数字均保留。这是一次性材料准备操作，不是回放引擎，也不在实验运行时重新生成内容。

尾部替换的原文字符均不含“※”，同长度替换使目标编辑距离等于替换数量；下表仅为材料构造核对。正式验收仍必须对实际text计算Levenshtein距离，不能读取此表作为结果。
