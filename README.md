## 实验与复现

- [第一轮实验与运行说明](experiment_v1/README.md)：70个主条件，比较A、B、C。
- [第二轮实验与运行说明](experiment_v2/README.md)：2366个唯一主条件，加入C1和24种页面顺序。
- [课题讨论与规则草案](课题讨论/01_问题与规则草案.md)

各轮目录包含程序、冻结输入、预期表、原始主运行与影子记录、汇总、测试和失败诊断。Python依赖和复现命令见各轮README。

本实验使用四页合成正文与确定性故障回放。C在部分永久失败和旧页回放条件下减少调用，也会截断延迟修复；C1缓解首轮覆盖前暂停，但仍有额外调用与误停。结果不表示真实文档总体概率，也没有直接证明优于课堂同类错误转人审规则。
