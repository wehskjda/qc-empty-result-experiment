# 已确认的第一版规则（编码前保存）

依据：用户于 2026-11-15 接受《02_实验规则_用例与预期结果.md》，明确授权实现。原讨论稿保留在 ../../课题讨论/；本文件与 protocol.json 将其转成编码前固定条件。

本实验是确定性受控故障回放，不调用真实网络、PDF 解析器、OCR 或大模型。T/O 是两个模拟方式接口。四个逻辑源页以 reference_pages/p1.txt 至 p4.txt 保存；参考数字单独保存在 key_numbers.json。返回接口只读取预存 faults.json；验收器独立读取参考文本计算正文 CER，并从实际返回正文提取字段数字，不相信 HTTP 200、claimed_page、成功提示或自报质量。

页面通过条件：NFC、连续空白合并、去除首尾空白后的字符级 Levenshtein 距离除以参考长度不超过 1/20，且 depth/temperature/salinity 三字段数值正确。每字段须在对应标签后唯一出现，缺失、重复或冲突均拒绝。普通数值用精确十进制比较；不以显示值四舍五入判阈值。参考答案与故障返回在编码前保存，策略不能查未来结果。

源页身份绑定文档版本与物理页序号。请求目标页决定参考答案，工具自报页码不起作用；每页首次通过才计新增。不同源页的相同正文不按内容哈希合并。成功页移出队列，并保存正文、验收证据和首次通过调用号。

共同调度：p1→p2→p3→p4 FIFO 轮询，每次访问一次调用；未通过页入队尾。初始方式 T。A 始终 T，无错误路由和方式次数限制。B/C 的同页同方式最多 4 次，网络失败也算；T 遇 HTTP 422 且 code=NEEDS_OCR 时关闭 T 转 O，否则未通过到第4次再转 O；O 到第4次未通过则关闭该页。转 O 后不返回 T。方式上限优先于网络失败通常的同方式重试路由。没有仍获准的方式时退出活动队列，但保留未完成页状态。

C 从第一次调用开始启用停滞，S=0，网络额度E=2。新验收源页使 S=0但不补E；无新页且 HTTP 状态为 408、502、503、504之一，并且E>0，则E减1且S原样冻结；其他无新页S加1。保护只看整数HTTP状态，不匹配错误文字或工具名。429、500、422、200和无状态响应不获本实验的网络保护；这是一份预先选定的实验允许表，不是对所有服务错误的通用分类结论。

总预算分别12/20，C的k分别2/3/4。每次调用先消耗总预算与方式次数，再验收、更新队列和方式、S/E，最后判断停止。停止主原因优先级：complete→budget_exhausted→methods_exhausted→stagnation；保留全部触发标志。完成即停，不必用满预算。预算耗尽与停滞同拍不算有余量的提前暂停。

结果索引固定为场景、源文档、源页、方式、该页该方式第n次尝试。网络失败占n；不依策略、预算、k或全局调用号改变返回。精确索引优先，明确repeat规则其次，否则各页默认正确正文。正文和错误字段原样保存；不以预设pass/CER字段代替计算。

七个场景为 F永久失败、N两次网络失败恢复、D成功却返回旧页、P持续新页、R单页四次修复才通过、S前三页需OCR且第四页普通、L四页各第四次才通过。各预算运行A、B、C(k2/3/4)，共70个主条件。A/B不随k重复计独立样本。确定性重复不能作为额外统计样本。

C发生停滞暂停时，先将主运行逐次记录、最终快照及主结果写入文件，计算摘要；随后deepcopy该快照按B续跑，预算仍为原12/20减已用次数，不能重置队列、页成果、尝试序号、修复历史或故障序号。影子使用独立状态和日志；主结果不得写入影子页或调用。主文件续跑后再核摘要，核对主状态未变。

主指标：完成页/4、总调用、无新增页调用、严格重复无进展调用、旧页返回、网络事件与保护、停止原因、未完成页。严格重复按同源页、同方式、实际输入/修复状态、规范化结果比对；尝试编号、自由错误文字、时间戳不构成新状态。另报旧页返回数。无新增不等于无价值，不能把必要修复前置步骤都称作浪费。

影子指标：额外调用、最终累计调用、最终页数、额外恢复页、文档错停。影子在原预算内完成4页才算文档错停；只多完成部分页单独记损失页。没有影子不填false来冒充经过反事实验证。主与影子调用分开，并公开影子评测开销。
