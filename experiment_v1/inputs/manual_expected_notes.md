# 预先保存的手推预期

日期：2026-11-15。来源为用户已经接受的 [第一版规则、用例与手工预期](../../课题讨论/02_实验规则_用例与预期结果.md) 第 8—9 节，以及同一轮聊天中的手工推导。

本目录的 `manual_expected.csv` 在实验程序实现和运行前保存。它是**事先给定的手推预期，不是实测结果，也不是由未来实验引擎生成的答案**。后续结果必须逐项与该文件对照；若有差异，保留原始运行记录并明确区分实现错误与预期修正，不回改这个原始预期文件来掩盖差异。

## 网格与列含义

七种场景 F、N、D、P、R、S、L，各使用总预算 12 和 20。每个预算下 A、B 各一行，C 的 k=2、3、4 各一行，共 `7×2×5=70` 行。

- `run_id`：例如 `F_L12_C_k2`，表示 F 场景、总预算 12、策略 C、阈值 2。
- `completed_pages`、`calls`、`stop_reason`：C 影子续跑开始前的**主运行**结果。
- `k`：A/B 留空，C 为 2、3、4。
- `stop_reason`：`complete` 全部四页完成；`budget_exhausted` 总预算耗尽；`methods_exhausted` 未完成页已没有获准使用的解析方式；`stagnation` 文档停滞暂停。
- `shadow_extra_calls`：从 C 暂停状态的独立副本按 B 继续后的额外调用数。
- `shadow_final_pages`、`shadow_total_calls`：影子结束时的页数与“主运行已用调用＋影子额外调用”。不能把这两列混进主运行结果。
- `lost_pages`：影子最终完成页数减去 C 主运行完成页数。
- `false_stop`：影子能在原总预算内完成全部四页时为 `true`，否则为 `false`。只有 C 的停滞暂停行填写影子相关列，其余留空，表示未启动影子续跑而不是“测得零”。

26 个 C 条件预期发生停滞暂停并启动影子续跑；其中 11 个条件预期构成文档错停。这是构造用例网格的计数，不能解释为真实文档总体的错停概率。

## 机制与手算依据

| 场景 | 手算依据 |
|---|---|
| F 永久失败 | 其余三页各一次通过；B 对 p1 的 T/O 各尝试四次，所以总共 11 次。C 最后一次新增在总第 4 次，随后 k 次无新增，在总第 6/7/8 次暂停。 |
| N 网络恢复 | p1 两次网络失败后第三次 T 成功，加其余三页首试，共六次；两次网络保护使全部 C 条件均完成。 |
| D 成功返回旧页 | p2 的 T/O 都返回 p1 旧正文，必须拒绝；次数计算与 F 一致。 |
| P 持续新增 | 四页各一次全部通过，共四次。 |
| R 单页延迟修复 | 前三页共三次；p4 第四次 T 通过，全部完成需七次。C 的 k=2/3 分别在总第 5/6 次暂停，影子再 2/1 次完成。 |
| S 首轮困难页 | B 按 T(p1)、T(p2)、T(p3)、T(p4)、O(p1)、O(p2)、O(p3) 七次完成。C 的 k=2/3 在第二/三次停止，k=4 在第四次遇新页清零。A 不按错误类型转 OCR，只能完成 p4。 |
| L 四页延迟通过 | 前十二次为四页各三次，均不通过；第十三到十六次才分别通过。C 从开始就启用守卫，在总第 2/3/4 次暂停。 |

## 跨预算敏感性

- F、D 的 A 在预算 12/20 下分别用满 12/20 次，均只完成三页。B 在 11 次时无可用方式，C 的暂停调用数也不随这两种预算改变。
- N、P、R、S 的 B/C 所需或暂停调用数都少于 12；因此这些条件不因总预算从 12 改为 20 而变化。S 的 A 仍会用满两种预算。
- L 专门检验预算边界：预算 12 时 A/B 用满预算仍零页，C 影子亦如此；预算 20 时 A/B 在 16 次完成，C 的三个 k 影子都能完成，因此这三个条件构成文档错停。
- “预算 12 下 L 不算文档错停”只表示相同 B 策略在原预算内也不能完成，不代表文档永远不可解析。

网络保护的冻结边界、方法第四次先验收以及暂停副本隔离等检查，应另外验证实现；本 CSV 不以重复运行确定性案例来扩大独立样本量。
