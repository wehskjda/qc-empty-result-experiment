## 2. 先限定“有效解析”的含义

建议首版只研究：**能够建立可信物理页清单的文档，逐页提取正文文本**。复杂表格、公式、图表语义和跨页关系暂不混入主问题。

若 PDF 损坏到连页数和页边界都无法确定，先记为 `document_unreadable`。它没有可核验的页级分母，不应混进完成页数指标。课程情境启发了这个问题，但当前素材并未证明案例 PDF 能否逐页打开；后续实验需要另选或构造有可信源页清单的材料。

建议采用以下受控实验验收方式，阈值仍待确认：

1. 测试前，人工核对每个源页的参考文本，并固定验收器版本。解析器不接触参考答案。
2. 非空白页须返回约定结构的正文文本；空字符串、只有错误提示、只有工具成功标志或只有文件路径均不通过。合法空白页须在可信清单中预先标明，另行验收。
3. 对输出与参考文本做相同的保守规范化：Unicode NFC、统一换行、合并排版造成的连续空白；保留数字、正负号、单位、标点和否定词。
4. 示例门槛：字符错误率 `CER = Levenshtein 距离 / 参考文本字符数 ≤ 5%`，并且预先列出的关键字段（标签、数值、单位等）全部一致。所有策略使用同一标准，不按结果分别调门槛。
5. 页面来源必须可追溯到该次实际输入的源页，不能只凭解析器自报页码验收。若请求第 7 页却返回第 2 页的已知内容，应判为错页或重复返回。

这一定义中的“有效”只表示通过约定标准，不表示完全无错或能够支持任意下游任务。参考答案参与验收，是用于隔离停止策略效果的受控实验条件；它不等于真实部署时已解决自动质量验证。未来可用格式、字段和独立抽检等在线检查替换，但应另测误验收与误拒绝，不能直接外推本实验结果。

## 3. 页面身份、去重和新增进展

每页使用稳定身份：`page_key = (原始文档 SHA-256, 原始物理页序号)`，序号统一从 1 开始。建立可信清单后固定不变。修复、渲染、OCR 或拆页产生的新文件必须保留到原页的映射，不能因派生文件哈希变化变成“新文档、新页面”。

建议由外层调度器生成单页输入，并记录原页身份、输入图像/文件摘要、操作和请求编号。不能让工具通过修改返回的 `page_number` 自行创造身份。

设 `V_t` 为第 t 次工具执行返回后，通过验收的源页身份集合，`P_t` 为累计已通过集合：

`P_t = P_(t-1) ∪ V_t`

`Δ_t = |V_t \ P_(t-1)|`

只有 `Δ_t > 0` 才是新增进展。主实验逐次处理单页，通常 `Δ_t` 只会取 0 或 1。验收通过的结果与证据立即保存，后续重试失败不能覆盖已保存成果。

| 返回情况 | 是否新增进展 |
|---|---|
| 某个源页第一次通过固定验收 | 是 |
| 同一个源页第二次通过，或换行、措辞、格式稍有变化 | 否 |
| 错误提示改写，或换了工具名称 | 否 |
| 新页只解析了一部分，尚未达门槛 | 否，但可另记部分质量用于事后分析 |
| 原文确实有两张内容相同的不同物理页，且分别通过来源和质量验收 | 两页分别计入 |
| 请求新页却重复返回旧页 | 否，不能仅按声称的新页码入账 |

内容摘要可用于发现重复输出，但不能替代源页身份。全局按正文哈希去重，会把原件中合法的重复页错误合并；只按输出页码去重，又可能被错页或缓存结果欺骗。

## 4. 暂停规则与网络故障：建议讨论版本

记总调用预算为 `B_total`、每页最多尝试次数为 `R`（包含首次）、停滞门槛为 `k`。这些参数必须在测试前固定；这里用到的 3、4、8 等数字只是反例或待验证候选，不是已经选好的最优参数。

- 总预算统计实际发生的工具执行：解析、OCR、修复、网络重试均计入。成功、失败、重复返回都计数；底层 SDK 隐藏重试须关闭或逐次记账。主实验采用串行、单页执行，避免批次大小改变一个调用的含义。
- 三种策略均完成即停；所有预算检查在下一次调用前执行，不允许超支。每页尝试次数按稳定源页身份累计，换工具或修改错误文字不清零。
- C 的停滞计数初始为 0。新增验收页时清零；无新增页的普通调用使它加 1；达到 `k` 时暂停整份文档，保留已验收页，输出未完成页号和具体原因。
- 暂停表示本次自动处理暂时结束，不宣称文档永久不可解析。实验主运行不自动重新开一轮预算，否则会隐性绕过停止规则。

对暂时性网络故障，建议采用**有限的计数保护**：

1. 依异常类型、HTTP 状态及结构化错误码的预定允许表分类，例如连接中断、超时和选定服务端暂时性错误；不能因为错误文字中有“网络”就得到保护。格式损坏、乱码、空正文、错页和旧页不是网络故障。
2. B 与 C 使用相同的分类、有限重试和退避规则；每次重试仍扣总预算并计入该页尝试上限。等待时间单独报告。
3. C 可以另设整份文档最多 `e` 次网络失败保护。被保护调用只**冻结**停滞计数，不增加也不清零；保护额度不因换页、换工具、改变错误文字或成功返回旧页而补充。额度用完后的无新增调用照常累计。
4. 比较 `e=0` 与一个小额度（例如 `e=2`），检验保护是否减少网络误停及是否拖长无产出的重试；不能预先断言有效。

因此，加网络保护后准确表述应为“累计连续未受保护的无新增调用达到 k 次”，其中保护调用冻结计数。不能一面说所有连续调用都计数，一面在实现中偷偷跳过网络故障。

“一次没有新增验收页”与“该次尝试没有价值”必须分开：修复链的必要前置步骤也可能暂时没有新增页。这是本研究要测的局限，而不是用词就能排除的问题。

## 5. 两个可复现的误停反例

以下都是为挑战规则构造的序列，不是已经运行得到的结果。均假定没有网络保护事件且预算充足，停滞门槛 `k=3`。

### 反例一：单页修复收益延后出现

只剩一个未完成页。四次连续修复/解析保留中间状态，结果质量依次为 40%、65%、85%、98%；示例验收门槛为 95%，且最后一次关键字段正确。

| 调用 | 观察到的变化 | 新验收页 | C 的停滞计数 |
|---|---|---:|---:|
| 1 | 恢复部分文本 | 0 | 1 |
| 2 | 字体映射得到修复 | 0 | 2 |
| 3 | 阅读顺序进一步修复，但仍未达门槛 | 0 | 3，暂停 |
| 4（若继续） | 完整解析达到门槛 | 1 | 本可清零 |

当该页上限 `R≥4` 且剩余总预算足够时，B 可以在第 4 次成功，C 却在第 3 次暂停。原因是“是否整页通过”的二值信号看不到中间修复收益。质量变好不能悄悄算成新页，否则就改了原假设；可将“有限修复宽限”另作消融，但不能无限因参数变化延长宽限。

### 反例二：全局停滞在首轮覆盖前误伤其他页

一份四页文档，前三页为扫描页，需要先发现错误再转 OCR；第四页为可直接解析的文本页。固定调度先完成四页首试，再按错误路由做第二轮。取总预算 8 次、每页上限至少 2 次。

| 调用 | 预定操作与结果 | 是否新增验收页 |
|---|---|---:|
| 1 | p1 原生解析：需 OCR | 0 |
| 2 | p2 原生解析：需 OCR | 0 |
| 3 | p3 原生解析：需 OCR | 0，C 暂停 |
| 4（若继续） | p4 原生解析成功 | 1 |
| 5—7（若继续） | p1、p2、p3 分别 OCR 成功 | 各 1 |

B 在第 7 次即可完成全部四页，C 则连正常的 p4 都没有尝试。这里的原因是**文档级暂停与页面调度的相互作用**，不同于同页修复的延迟收益。

可验证的窄改动是“首轮页面覆盖后才启用停滞守卫”，但必须仍受原总预算限制；它是另一个变体，不能悄悄替换原始 C，也无法保证解决反例一。页面排列顺序应变化测试，避免恰好把好页排在前面就掩盖误停。

这两个反例也说明：仅凭过去 k 次没有新验收页，不可能确定下一次必然无收益。永久失败与下一次成功的任务可以有完全相同的失败前缀，规则只能管理风险与成本，不能给出零误停保证。

## 7. 三策略比较需要提前锁定的条件

| 策略 | 规定的差别 |
|---|---|
| A | 完成即停，否则只受总调用预算约束，不加每页次数和文档停滞守卫。 |
| B | 同总预算；增加每页尝试上限与固定的错误分类处理。耗尽该页次数后仍可处理其他页。 |
| C | **B 加文档级新增验收页停滞守卫**，其他调度、工具和错误路由与 B 一致。 |

A→B 是重试控制组合效果；B→C 才用于归因文档停滞守卫的增量效果。三者共享源文档、验收标准、工具集合和预先约定的基础调度；主结果中不能顺便给 C 更强的修复器或更有利的页面顺序。

“同一随机种子”本身不够，因为策略发出的调用数不同，随机数消费会错位。受控故障可预先按 `(文档、源页、真实操作及参数/输入状态、第几次尝试)` 键控生成，使相同操作在相同状态遇到相同故障。若研究按真实时间恢复的网络故障，应另用共同外生时间线，同时记录退避和实际等待，不混用两种故障语义。

建议后续围绕四个差异验证，暂不扩成大系统：

1. 改写错误、工具改名、旧页重复返回时，新增验收页信号是否能持续识别停滞。
2. 改变 k 时，完成页数、调用数与误停损失怎样变化；参数在独立开发集选择，不能看测试结果挑最好值。
3. 修复链长度和页面顺序变化时，两个反例机制是否出现；“首轮覆盖后启用”能缓解多少。
4. 网络保护额度 `e=0` 与小额度的差异，是否以更多调用/等待换来更少网络误停。

## 8. 指标、误停反事实与结果解释

- **完成页数**：唯一已验收源页数，另报占预先规定目标页数的比例；完成文档率要求所有目标页通过。
- **总调用次数**：实际工具执行次数；另报等待、时间或成本，避免把不同代价工具视为完全等价。
- **无新增页调用**：`Δ=0` 的调用数。它客观可计，但不自动表示浪费。
- **重复无进展调用**：可另记同一源页、相同输入处理状态、相同实际操作/规范化参数下，再次出现相同规范化失败或旧结果且无新验收的调用；错误文字、时间戳、工具别名不应伪造新状态。另记重复返回已验收源页的次数。这些是可观测重复指标，仍不证明每一次重试在决策时都无价值。
- **提前暂停**：仍有目标页未验收且预算未耗尽时，由停滞守卫暂停。提前暂停不自动等于错停；预算耗尽、全部可用页重试耗尽和停滞暂停须分别记原因。

为判断“本来能够完成”，在 C 暂停时保存完整状态，**只关闭停滞守卫**，继续按照相同 B 调度、同一故障环境和原预算剩余额度运行：

- 若该反事实续跑在原总预算内完成全部目标页，计为一份文档错停。
- 若只能多完成部分页，计为损失页数，不能冒充整份文档本来可完成。
- 续跑不能更换模型、修复器或增加预算，也不能清空修复状态、重试次数或故障历史。
- 反事实续跑只是离线评测，不算进 C 主运行的调用数；其额外评测开销另外记录，不能隐藏。

至少同时报告：所有任务中的文档错停率、C 发生停滞暂停的任务中的条件错停率、平均及总损失页数，并给出明确分母。调用节省可报 `calls_B - calls_C`，但须与完成差异并列；少完成工作导致的调用减少不能单独包装成效率提升。

待确认的核心约定：纯文本页范围与验收门槛；C=B+守卫；网络保护仅冻结且全程有限；主策略不加入隐性修复宽限。之后再确定预算、R、k 的候选范围与故障样本，编写实验代码。
